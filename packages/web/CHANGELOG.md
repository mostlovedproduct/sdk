# Changelog

Changes to `@mostlovedproduct/web`. While the version is `0.x`, a minor version can include breaking changes.

`https://cdn.mostlovedproduct.com/mlp.js` always serves the latest release. Each release below also lists its pinned script-tag URL, which never changes, and the `integrity` value to load it with Subresource Integrity.
